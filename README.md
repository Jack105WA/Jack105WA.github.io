## Deployment

GitHub Actions publishes the contents of `Website/` as the website root. The workflow runs automatically on every push to `main`.

In **Settings → Pages**, set **Build and deployment → Source** to **GitHub Actions**. Do not select branch deployment; that would publish this README instead of the website.

The website's original folder structure is preserved inside `Website/`, so its root-relative links and existing public URLs continue to work after deployment.

Most site code is AI-assisted. Please do not copy or reuse the original code, design, or content without permission.
